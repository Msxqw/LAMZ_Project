## Структура проекта

- `main.cpp` — точка входа в приложение.
- `mainwindow.h` — описание главного окна и слотов.
- `mainwindow.cpp` — реализация интерфейса и логики работы.
- `protocol.h` — описание структуры пакетов и команд.
- `themes.h` — оформление интерфейса в тёмной теме.

### Требования
- Qt 6 или Qt 5 с поддержкой Widgets и Network.
- Компилятор C++ с поддержкой стандарта C++17.
- CMake.

### Сборка
1. Клонируйте репозиторий.
2. Создайте папку для сборки:
   ```bash
   mkdir build
   cd build
   ```
3. Сконфигурируйте проект:
   ```bash
   cmake ..
   ```
4. Соберите проект:
   ```bash
   cmake --build .
   ```

### Запуск
После успешной сборки запустите исполняемый файл приложения.

## Настройка подключения

По умолчанию в интерфейсе указаны:
- IP-адрес: `192.168.100.9`
- Порт: `12345`

При необходимости значения можно изменить перед подключением.
